# Pirate ship thumbnails – ROUND 1 (real 3D Blender scenes)

**Status:** round-1 proofs for Playtest + Art critique. These are **not final**. Waiting for round-2 feedback; no further iterations were made after the 3 proofs.
**Staged scene:** every environment piece (sand, lagoon, water, sky, palms, rocks, jungle) is a **RENDER_ONLY** staged tropical cove for thumbnails. It is **not** the game layout, not the v30 historical placement, and not the v31 free-roam map. The source ship is not claimed to be identical to the live game.

All three are 1280×720 PNGs with no text. They were rendered in Cycles on the **CPU** (Roblox Studio was open on the PC and was not touched) at 48 samples with adaptive sampling, OpenImageDenoise, the **Standard** view transform, look None and exposure −0.15.

## Deliverables
- `pirate_thumbnail_round1.blend` is one packed file containing 3 scenes (`Thumbnail_A_Hero`, `Thumbnail_B_Octopus`, `Thumbnail_C_Adventure`).
  - The scenes share the ship collections `Visual`, `Props` and `Ramps`, linked rather than copied, so the transforms stay unchanged.
  - They also share `RENDER_ONLY_Environment/RO_Env_Common`, plus one per-scene collection `RO_Env_<A|B|C>_only`.
  - Each scene has its own camera, a key sun, a shadowless fill and the shared sky world. All images are packed: the ship palette plus the 2 kit palettes.
  - The source file's original `Scene` is kept as it was (it still links `Collision`). Use the `Thumbnail_*` scenes.
- `previews/A_round1.png`, `B_round1.png`, `C_round1.png`
- `manifest.json` holds cameras, lights, framing numbers, triangle counts, every kit instance (prop, kit, position, scale, yaw, tris), source/output hashes and validation results.
- `src/` contains the build, render and validate scripts, the rebuild wrapper, the original kit generators and a trimesh shim.
- `textures/kit_v1_palette.png` and `textures/kit_v22_palette.png` are generated by the kit scripts and also packed in the .blend.
- `build/` holds generated kit geometry JSON and `build_report.json` (all regenerable).
- `logs/` holds build, render and validate logs plus probe scripts. Logs written by the PS 5.1 wrapper are UTF-16.

## Ship = approved source, unchanged
- Source: `inputs/start_ship_whimsy_v5_1.blend` @0852f9d. SHA-256 is `fd7798af4ca9bd107dba927bdf663e7017c04f8c4c7649b518b5c78c8d4bcacd` both **before and after** the build.
  - The source is opened by Blender and only ever saved *as a copy* to `out/`.
- `validate_round1.py` compares all 239 source objects against the output file:
  - mesh vertex-coordinate, loop and material-index hashes
  - basis transforms (location, rotation, scale, deltas, parent inverse)
  - `matrix_world` for every non-Collision object
  - parent, modifiers, and all material node input values
- Result: **identical** (`ship_objects_identical: true`).
  - Note: the 190 Collision objects carry a stale cached `matrix_world` in the source file because they are never evaluated there. Blender refreshes that cache on save. Their real transforms are identical, and they are not rendered.
- The only change to source objects is visibility: the 4 helper empties (`Spawn`, `Tee1`, `RampStart`, `CupRef`) are set to `hide_render`. The `Collision` collection is not linked into the thumbnail scenes.
- Nothing was added to the ship: no holes, cups, flags or gameplay. The green Felt ramp and the pier are the ship file's own `Ramps` and `Pier` meshes.
- The material palette is unchanged. Coral reads warm (Standard view transform, not AgX).

## Environment provenance (originals reused vs approximations)
**Original kit models, reused as-is.** The generators were run **unmodified**. The files in `src/kit_*_src/` are byte-identical copies of `inputs/kit_*_src/`.

| Kit | Generator (sha256 prefix) | Props used |
|---|---|---|
| kit_v1 | `gen_kit.py` (8aad2e4e) + `kit_lib.py` (24ab004d) | `kit_palm_s/m/l`, `kit_palm_lean_a/b`, `kit_rock_s/m/l`, `kit_fernclump`, `kit_leafclump` |
| kit_v22 | `gen_kit22.py` (893aa283) + `kit_lib.py` (e26ac9cf) | `kit_boulder_pile`, `kit_canopy_wall` (rear jungle mass) |

- kit_v26 (`gen_kit26.py`) only restyles `kit_ruin_wall`, so it is not used.
- How the meshes get into Blender: the generators write geometry JSON, and the build script converts it with the same axis mapping as the original `build_kit.py` (`B(v)=(x,-z,y)`). Each kit uses its own palette PNG on a Closest-interpolated image texture, and normals are recalculated per island.
- Dependency workaround: `trimesh` is not installed on the PC. `src/trimesh_shim/trimesh/` is a small pure-numpy stand-in written for this job, covering only the subset the kit code calls (`Trimesh`, `creation.box`, `transformations.*`, `geometry.align_vectors`, `submesh`, `face_normals`, ...). The generators also need numpy and Pillow, which are in the system Python.
- Render-only placement changes: kit palms are scaled ×1.85 (×1.76 for one), rocks ×1.4–2.3 and clumps ×1.6–2.2, so they read against the ~400-stud ship. Placement, yaw and scale are recorded in `manifest.json`. The kit meshes themselves are unchanged.

**Approximations made for this job (procedural, render-only, toy-faceted style):**
- `RO_CoveTerrain` is a jittered 7-stud triangulated height field with flat shading.
  - Shape: a foreground beach, a bow beach under the octopus, a raised jungle mound rear-right and a small far-left spit. A shallow lagoon shelf surrounds the ship and pier, a pool sits in front of the port side, and the hull is seated in shallow water (keel ~3 studs under the surface, never floating).
  - Colour comes from height: deep-sea blue, then turquoise lagoon seabed, pale wet sand, golden sand, and jungle green on the mound top.
- `RO_WaterSurface` (z = 1.0) is a real transparent surface: tinted Transparent BSDF, 16% turquoise body, and a Fresnel-weighted soft glossy with small noise-bump waves. The seabed shows through it and stays sun-lit, because the water casts no shadow.
- `RO_SeaFloorFar` is a deep floor plane beyond the terrain patch. `RO_TropicalSky` is a gradient world.
- The reference images were used only as composition and colour guidance. Nothing is projected or textured from them: no background plates, billboards or image planes.

## Rebuild (from the job root; one Blender process at a time)
Fully automatic (PowerShell, all paths relative to the script):
```
powershell -ExecutionPolicy Bypass -File out\src\rebuild_round1.ps1 [-Blender "<blender.exe>"] [-Python python] [-Source inputs\start_ship_whimsy_v5_1.blend]
```
Manual equivalent (Blender 5.2.2, Python 3.12 with numpy + Pillow):
```
set PYTHONPATH=out\src\trimesh_shim
python out\src\kit_v1_src\gen_kit.py   out\build\kit_v1_geom
python out\src\kit_v22_src\gen_kit22.py out\build\kit_v22_geom
set PYTHONPATH=
blender -b inputs\start_ship_whimsy_v5_1.blend --python-exit-code 1 --python out\src\build_thumbnail_round1.py -- --kit1 out\build\kit_v1_geom --kit22 out\build\kit_v22_geom --output out\pirate_thumbnail_round1.blend
blender -b out\pirate_thumbnail_round1.blend --python-exit-code 1 --python out\src\render_round1.py -- --scene A
blender -b out\pirate_thumbnail_round1.blend --python-exit-code 1 --python out\src\render_round1.py -- --scene B
blender -b out\pirate_thumbnail_round1.blend --python-exit-code 1 --python out\src\render_round1.py -- --scene C
blender -b --factory-startup --python-exit-code 1 --python out\src\validate_round1.py -- --source inputs\start_ship_whimsy_v5_1.blend --output out\pirate_thumbnail_round1.blend
```
The build script also takes `--res WxH` (default 1280x720) and `--samples N` (default 48). The render script also takes `--out`, `--samples` and `--percent`. The full wrapper was run end-to-end once to verify the rebuild (REBUILD_ROUND1_OK, validation ALL_OK). Cycles multithreaded denoising is not bit-exact, so PNG hashes vary slightly between runs while the image stays the same.

## Limitations / known facts (for the reviewers; not a critique)
- The staged cove is **not** the game environment or layout. Island shape, water level and dressing were all chosen for the thumbnails.
- The octopus is a figurehead on the bowsprit, so it hangs above the bow beach instead of standing on sand as in AI ref B. The ship was not moved, and sand was not piled up to the octopus, because that would bury the bow hull.
- C uses the prior C camera only as its starting point. The view was raised and moved forward so the near right-hand rail post no longer blocks it, and the cove shows over the port rail. The heeled port bulwark/bow-raise slab still fills the right-middle of the frame. That is approved ship geometry and was not cut.
- C proof history: the first C render kept the old framing, and one polish attempt (eye z 47) regressed, showing cabin roof on the left and a big stern bulwark on the right. The delivered C uses a middle setting (eye z 40). No other proof iterations were made.
- The B-only far-left spit palms (`RO_Env_B_only`) end up hidden behind the hull and pier in the final B framing, so they don't contribute visibly. They are left in place for round-2 framing changes.
- A's upper-left keeps ~35%×30% mostly quiet sky and horizon; the top of the stern curl reaches into the lower-left corner of that zone (v ≈ 0.73). In B, the masts sit left of centre, so the quiet zone is smaller there.
- This is a round-1 proof: 48 samples with denoising, and no final-quality render.
