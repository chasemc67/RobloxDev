# C05 Aerial palette

Hex values are medians of pixel clusters sampled from the round-1 concept image, not estimates.

| Hex | Used for |
|---|---|
| `#E5F0EE` | Main shell: head, torso, fan housings, legs |
| `#288FA2` | Teal: brow, chest, fan rims, knee cuffs |
| `#21626C` | Dark teal: recessed panels and fan interiors |
| `#F1C63C` | Yellow: tabs, antenna tip, stripes, bomb spheres |
| `#BB932E` | Deep gold: shaded yellow and bomb spots |
| `#AEF5F7` | Glow: eyes, chest core, muzzle, foot thrusters |
| `#1B2123` | Visor glass, joints, soles |
