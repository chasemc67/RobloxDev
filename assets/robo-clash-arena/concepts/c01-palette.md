# C01 Scout palette

Hex values are medians of pixel clusters sampled from the round-1 concept image, not estimates.

| Hex | Used for |
|---|---|
| `#E8E9EC` | Main shell: helmet, chest, thighs, blaster body |
| `#35BDE1` | Cyan armor: stripe, shoulders, knees, weapon trim |
| `#2298BB` | Deep cyan: shaded armor and roller housings |
| `#1A6B82` | Dark teal: panel lines and inner armor |
| `#90E2F0` | Glow: visor slit, mine lights, wheel axles |
| `#17191B` | Joints, faceplate, muzzles, wheels |
