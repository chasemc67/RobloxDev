# S04 Homework Desk palette

Hex values are medians of pixel clusters sampled from the round-1 concept image, not estimates.

| Hex | Used for |
|---|---|
| `#8BAE7A` | Play-mat floor |
| `#FED960` | Center star, sticky-note cube, ruler |
| `#E45D51` | Red fort, ramps and red fence blocks |
| `#4359AF` | Blue tunnel building and blue blocks |
| `#F98E98` | Pink eraser block |
| `#F79E5C` | Crayons, flag, orange fence posts |
| `#FAD3B0` | Desk wood around the playset |
