## Frame and scale
Studs; X east, Y up, Z south; water level Y = 0. World origin = centre of the 819x461 concept map; **3 studs per map px** (island about 2400 x 1200 studs).
Why 3: the concept map draws the wreck about 700 studs long, but the wreck sheet says 220. At 3 studs/px the pads (30x60 felt, 68 with rim) and the wreck at sheet size fit; the wreck is therefore smaller on the map than drawn. Pad centres keep the map positions. `ground.baseY` (R28) cannot describe this (pads run from 4.5 to 90 studs): see questions.
